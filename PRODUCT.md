# Product

## Register

brand

## Users

AI application developers and platform engineers evaluating or integrating a persistent memory layer. They need to understand PowerMem's value quickly, inspect credible code, and reach documentation without decoding decorative marketing.

## Product Purpose

PowerMem provides persistent, searchable memory infrastructure for AI applications and agents. The website should establish technical confidence, demonstrate a simple integration path, and make documentation easy to scan.

## Brand Personality

Precise, confident, restrained.

## Anti-references

Avoid neon-heavy AI landing pages, oversized headlines that fragment into many lines, decorative glow, generic SaaS card walls, low-contrast syntax themes, and visual effects that compete with technical content.

## Design Principles

1. Show the product through concise, credible code.
2. Keep the hierarchy calm enough for technical reading.
3. Use OceanBase blue as a deliberate signal, not ambient decoration.
4. Make light and dark modes equally intentional.
5. Prefer direct structure over compatibility layers or hidden fallbacks.

## Accessibility & Inclusion

Target WCAG AA contrast, visible keyboard focus, reduced-motion support, readable code at common laptop widths, and responsive layouts without horizontal overflow.
