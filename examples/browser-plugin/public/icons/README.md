# PowerMem Extension Icons

This directory should contain the following icon files:

- icon16.png (16x16) - Toolbar icon
- icon48.png (48x48) - Extension management page icon
- icon128.png (128x128) - Chrome Web Store icon

## Temporary Setup

For development, you can create simple colored square PNG files with these dimensions, or use placeholder images.

You can use online tools like:
- https://www.favicon-generator.org/
- https://www.photopea.com/

Or create them programmatically using Node.js with the `sharp` library.

## Design Guidelines

- Use the PowerMem brand colors
- Keep the design simple and recognizable
- Ensure the icon is clear at 16x16 size
- Use transparent background
