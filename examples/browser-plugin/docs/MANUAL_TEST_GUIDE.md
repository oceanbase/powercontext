## 🚀 步骤 1：加载扩展到 Chrome

### 1.1 打开扩展管理页面

在 Chrome 浏览器中，通过以下任一方式打开：

**方式 1：地址栏输入**
```
chrome://extensions/
```

**方式 2：菜单导航**
1. 点击右上角 `⋮` (三个点)
2. 更多工具 → 扩展程序

### 1.2 启用开发者模式

在扩展管理页面右上角，打开"**开发者模式**"开关

### 1.3 加载扩展

1. 点击左上角 "**加载已解压的扩展程序**" 按钮
2. 在文件选择对话框中，导航到：
   ```
   d:\powermem\browser-plugin\dist
   ```
3. 选择 `dist` 文件夹，点击"选择文件夹"

### 1.4 确认加载成功

✅ 应该看到：
- 扩展卡片显示 "PowerMem"
- 版本号：0.1.0
- 状态：已启用
- 扩展图标出现在浏览器工具栏

⚠️ 如果出现错误：
- 查看错误信息（通常是文件缺失或 manifest 配置问题）
- 确认 dist 目录包含所有必要文件

## 🧪 步骤 2：基础功能测试

### 2.1 测试 Popup 界面

**操作步骤**：
1. 点击浏览器工具栏的 PowerMem 图标
2. Popup 窗口应该弹出

**预期结果**：
- ✅ Popup 正常打开
- ✅ 显示搜索框
- ✅ 界面布局正常
- ✅ 无控制台错误

**可能遇到的问题**：
- ❌ Popup 无法打开：检查 `dist/src/popup/index.html` 是否存在
- ❌ 样式错误：检查 CSS 文件是否正确加载

### 2.2 测试设置页面

**操作步骤**：
1. 在 Popup 中找到"设置"按钮或链接
2. 或右键点击扩展图标 → "选项"

**预期结果**：
- ✅ 设置页面正常打开
- ✅ 可以输入服务器地址
- ✅ 可以输入 API Key
- ✅ 显示"测试连接"按钮

### 2.3 测试连接配置

**操作步骤**：
1. 在设置页面输入测试配置：
   ```
   服务器地址: http://localhost:8000
   API Key: test-api-key
   ```
2. 点击"测试连接"按钮

**预期结果**：
- 如果 PowerMem 服务器未运行：
  - ✅ 显示连接失败提示
  - ✅ 错误信息清晰
  
- 如果服务器正在运行：
  - ✅ 显示连接成功提示
  - ✅ 配置被保存

### 2.4 测试内容脚本（文本选择）

**操作步骤**：
1. 导航到任意网页（如 https://example.com）
2. 用鼠标选中一段文本
3. 查看是否出现保存按钮或右键菜单选项

**预期结果**：
- ✅ 选中文本后有反馈（保存按钮/右键菜单）
- ✅ 点击保存后有提示

**注意事项**：
- 内容脚本在 `chrome://` 和 `chrome-extension://` 页面不会运行（Chrome 安全限制）
- 请在普通网页测试

### 2.5 测试侧边栏（如果已实现）

**操作步骤**：
1. 右键点击扩展图标
2. 选择"打开侧边栏"（或在 Popup 中点击侧边栏按钮）

**预期结果**：
- ✅ 侧边栏在浏览器右侧打开
- ✅ 显示记忆列表
- ✅ 可以滚动和交互

## 🐛 步骤 4：调试和问题排查

### 4.1 打开开发者工具

**Popup 调试**：
1. 打开 Popup
2. 右键 Popup 界面 → "检查"
3. 查看 Console、Network、Elements 面板

**Background 脚本调试**：
1. 进入 `chrome://extensions/`
2. 找到 PowerMem 扩展
3. 点击"检查视图"下的"Service Worker"或"背景页"

**Content 脚本调试**：
1. 在普通网页按 F12
2. 在 Console 中可以看到 content script 的日志
3. 在 Sources 面板可以找到 content script 文件

### 4.2 常见问题排查

**问题 1：扩展图标不显示**
- 检查 manifest.json 中的 action.default_icon 路径
- 确认图标文件存在：`dist/icons/icon16.png` 等

**问题 2：Popup 空白**
- 打开 Popup DevTools 查看控制台错误
- 检查 `dist/src/popup/index.html` 和相关 JS 文件
- 确认 React 库正确加载

**问题 3：API 请求失败**
- 检查服务器地址配置
- 确认 API Key 正确
- 查看 Network 面板的请求详情
- 检查 CORS 设置

**问题 4：样式错误**
- 检查 CSS 文件是否正确加载
- 查看 manifest.json 的 web_accessible_resources
- 确认 CSS 路径正确

### 4.3 重新加载扩展

修改代码后需要重新加载：

**方式 1：扩展管理页面**
1. 进入 `chrome://extensions/`
2. 找到 PowerMem 扩展
3. 点击"刷新"图标（🔄）

**方式 2：快捷键**
- 在扩展管理页面按 `Ctrl+R` (Windows) 或 `Cmd+R` (Mac)

**注意**：
- 重新加载后需要刷新正在测试的网页（使 content script 生效）
- Background 脚本会自动重启
