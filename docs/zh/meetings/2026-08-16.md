## 项目介绍与规划

- PowerContext 用于管理 Agent 的上下文资产，包括 Source、Memory 和 Skills。
- 项目仍处于早期阶段。当前 LoCoMo 基准测试成绩约为 90%，比 PowerMem 提高 3 个百分点。
- 后续将扩展 Source 类型，完善制品管理和可观测性，并接入更多 Agent 框架。

PowerContext Server 之间的适配层。
