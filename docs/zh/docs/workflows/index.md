# 管理上下文

按当前需要保存或使用的信息选择工作流：

| 需求 | 入口 |
| --- | --- |
| 保存决策并召回相关历史 | [Memory 与上下文](memory-and-context.md) |
| 跨会话或 Agent 继续任务 | [Memory 与 Handoff](memory-and-handoff.md)、[交接报告](use-handoff-report.md) |
| 保留可复用的经验或步骤 | [Experience 与 Skill](experience-and-skill-lifecycle.md) |
| 从 Prompt 或外部数据采集证据 | [Sources 与采集](sources.md) |
| 隔离项目并控制访问 | [Scope 与访问控制](scopes-and-access.md)、[Scope Profile](use-profiles.md) |
| 读取版本、管理标签或配置提示词 | [Artifact](artifacts.md)、[标签](manage-artifact-tags.md)、[Prompt](manage-prompts.md) |

这些指南描述当前 `master`。使用前核对[集成能力](../integrations/capabilities.md)，
不要假设 Agent 暴露了与 HTTP API 相同的全部操作。
