新用户从快速开始进入：默认配置完整记忆和 Dashboard，需要 Generation 与 Embedding 模型 API；
没有独立模型 API 时可以选择基础记忆，验证显式保存与召回。
本站命令使用 `oceanbase/powercontext` 的默认安装来源，Server 与插件保持同源。

平台：macOS、Linux；Windows `experimental`。版本选择见[安装与运行](get-started/install-and-run.md)。
