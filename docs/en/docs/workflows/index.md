# Manage context

Choose the workflow for the information you need to keep or use:

| Need | Start here |
| --- | --- |
| Save decisions and retrieve relevant history | [Memory and context](memory-and-context.md) |
| Continue a task across sessions or Agents | [Memory and Handoff](memory-and-handoff.md), [Handoff Report](use-handoff-report.md) |
| Keep a reusable lesson or procedure | [Experience and Skill](experience-and-skill-lifecycle.md) |
| Capture evidence from prompts or external data | [Sources and capture](sources.md) |
| Separate projects and control access | [Scopes and access](scopes-and-access.md), [Scope profiles](use-profiles.md) |
| Read revisions, organize tags, or configure prompts | [Artifacts](artifacts.md), [Tags](manage-artifact-tags.md), [Prompts](manage-prompts.md) |

These guides describe current `master`. Check [integration capabilities](../integrations/capabilities.md)
before assuming an Agent exposes the same operations as the HTTP API.
