# Which issue or RFC does this PR close?

关联 [oceanbase/powercontext#2074](https://github.com/oceanbase/powercontext/issues/2074)。
本 PR 交付有界证据准入的评估实现及受限研究结果，唯一冻结决策为 **`insufficient_evidence`**。
不使用自动关闭关键词；是否接受此受限结果关闭研究 issue，由维护者审查决定。

# Rationale for this change

现有 Source 数量缩减无法处理单个 Source 的完整投影已经超过预算的情况。
混合证据中的大字段、工具文本和引用历史还会占用预算并产生归因风险。
本评估比较完整投影、窗口缩减和有界片段，分别衡量输入覆盖、生成质量、支持范围、确定性、取消和成本。

候选在离线输入覆盖上有改善，但真实生成存在无效引用、Unicode 字面量损失、复合候选和错误归因。
这些失败保留为研究结果，不能用输入覆盖改善抵消，也不能据此推断所有有界策略都没有价值。

# What changes are included in this PR?

- 新增 `evaluation/memory/evidence_admission/` 的版本化 CLI、合成清单、准入策略、确定性报告、
  无模型测试和显式选择加入的线上运行命令。
- 使用实际 Source 写入、持久化、重读和投影构造提取输入；线上执行调用真实
  `AtomicMemoryGenerationPipeline`。三个正式 arm 使用共同冻结的来源、指令、模型设置和预算。
- 夹具覆盖单源及多源溢出、混合字段、位置事实、字面量、Unicode、故障、不可能完整性、重放、Scope 隔离及取消。
- 区分完整、有界、不可用和取消状态，记录不可变身份、范围、遗漏原因、输入输出哈希及成本预留。
- 保留全部历史协议与失败记录；上游整合后的必填 `description` 校验不用于补写原响应，
  旧测量只在原提交和锁定环境下解释。
- 增加只读的人工抽查绑定与校验工具，以及独立的审阅附录、17条定位确认表和未预选答案的模板。
  人工部分判断与原机器评分分别保存，不代签未审候选、不覆盖原会话。
- 保留与评估相关的工程修复：冻结 JSON 原字节检查、LongMemEval evidence 能力类型边界、
  评估计数校验及 Git 冻结测试前置目录处理。与已落地的 capture-ownership 共存，所有权污染与大小准入独立评分。

完整工程整合范围见 `UPSTREAM_INTEGRATION.zh.md`；验收逐项对照见 `ACCEPTANCE_CLOSEOUT.zh.md`。

原533项语义未决保持原状态，其中226项来自有效输出，307项来自被拒绝输出。

两次历史不可用调用的请求文件存在，但没有找回原响应、解析输出或用量。
不将未知用量计零、不重试以替换原记录，也不改冻结门槛使其进入其他决策。
累计已知费用上界 ¥3.521362，加未知调用预留 ¥4.227072，受保护总额 ¥7.748434，
低于批准的累计 ¥20；这些是费用上界与预留，不是账户账单。此次整理新增 provider 请求为0。

## 决策与限制

当前候选不满足正向生产后续门槛。按事前冻结的报告规则，语义未决、两次未知用量及缺失审计使
最终决策保持 `insufficient_evidence`，不能在观察输出后改成 `no_production_change`。
完整审阅会增加证据，但不会自动恢复缺失响应。

没有可信结构来源的 tier arm 不适用；私有语料属于选择加入项。
当前结果限定于已测合成负载、单一 provider 配置及原提交；模型别名不保证物理模型快照。
本地 SQLite、受控传输及取消夹具不证明所有远端后端、宿主或 provider 的取消和退款行为。
上游整合后的 schema 没有新增线上公平比较，不将旧实测追认为当前运行时的结果。
