# V2 离线比较结果

本结果只覆盖模型无关准备。所有真实 provider 请求均为 0；代码未提交，两个运行的唯一决策均为 `insufficient_evidence`。
原始回归集改善不代表任意事实位置都可保留，也不能代替线上提取、归因和人工语义审计。

## 原始回归矩阵

20 个样例 × 4 个实验组 × 3 档预算 × 3 次重放，共 720 个样本。
v1/v2 有 180 对样本；原有 8 个失败组合全部修复，24 个失败样本降为 0。
可共同容纳的必要事实保留：v1 为 156/216，v2 为 216/216。
比较使用相同的 v1 事实参考输入编码，未放宽可容纳性、标注或 100% 门槛。

| 样例 | 预算 | v1 必要事实 | v2 必要事实 | 重放次数 |
| --- | ---: | ---: | ---: | ---: |
| many-source-overflow | 2048 | 1/8 | 8/8 | 3 |
| many-source-overflow | 4096 | 2/8 | 8/8 | 3 |
| mixed-scaffolding | 2048 | 0/1 | 1/1 | 3 |
| mixed-scaffolding | 4096 | 0/1 | 1/1 | 3 |
| mixed-scaffolding | 8192 | 0/1 | 1/1 | 3 |
| observation-overflow | 2048 | 1/2 | 2/2 | 3 |
| positional-facts | 2048 | 1/3 | 3/3 | 3 |
| repeated-history | 2048 | 0/1 | 1/1 | 3 |

全部原始样例未观察到已保留事实身份、字面量身份、完整证据状态或失败/取消处理的退化。
“不可能完整”样例也参与非退化比较，仍为 bounded，不会因其保留数量增加而声称完整。
全部样本无 Memory 写入和生产游标推进，输入重放确定性及取消检查通过。
原始 540 个 v1 对照样本与历史结果的输入哈希、物化/投影、引用、遗漏、状态、窗口序列和既有评分完全一致；新增用量字段和延迟不参与该等价检查。

## 额外变体压力矩阵

8 个固定合成变体 × 4 组 × 3 预算 × 3 次重放，共 288 个样本。
v2 保留 159/171 个可共同容纳的必要事实；
未观察到相对 v1 的事实或字面量身份退化，但仍有 4 个失败组合、12 个重复样本丢失必要事实：

- `validation-off-center-facts`：2K、4K、8K 均为 2/3，中部偏离采样点的事实遗漏。
- `validation-metadata-pressure`：2K 为 1/2，多字段压力下尾部事实遗漏。

这些样例是合成开发压力集，不是盲测或真实宿主数据。已知失败保留在结果中，不通过修改标签、挑选重复或降低门槛隐藏。
因此，v2 尚不能宣称在扩展数据范围满足完整保留门槛，更不能仅凭原始回归集通过而授权生产后续。

## 成本与实现边界

原始矩阵中候选的潜在调用数从 135 增至 159（+17.8%）；
累计估算输入从 487,545 增至 525,633 token（+7.8%）。
这不是实际 provider 用量或费用；多 Source 完整窗口可能需要多次请求。
每次请求仍受 2K/4K/8K 预算限制，每个 v2 样本最多 16 次准备调用、累计输入最多为单次预算的 8 倍。
预算不足时明确记录 resource_budget 并拒绝完整完成。没有吞吐、增量成本或生产性能改善的承诺。

测试为 93 项评测测试通过；与 LongMemEval 联合为 340 项通过、1 项既有能力缺口跳过。
Ruff、格式、prek、根工程和新增模块类型检查、锁文件及 wheel 数据加载验证通过。
evaluation 全量类型检查仍有既有 `ScopedAtomicMemory.evidence` 缺失诊断，未修改生产 API 掩盖该问题。
