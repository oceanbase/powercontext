## 最新真实输出的证据边界

v9 首组 exact-literals / 4096 / repetition=0 已执行 v5 和 v9 各一次，共两次真实请求。
两个协议均保留四个必需原子事实和四个精确字面量，v9 将独立作业身份与阈值合并到一个候选，
因此冻结原子性门槛失败，会话已停止。其余 44 组、100 次计划调用未运行。

旧整句 scorer 在两个协议下均为 0/1，并保留 unresolved；这不代表语义事实全部丢失。
[v10 评分合同](V10_PROTOCOL.zh.md)分别报告旧整句分数、原子事实覆盖和父事实语义覆盖，
父事实只有在全部子事实受支持且精确字面量齐全时才计为保留。历史复合候选保持一个候选，继续判为原子性失败。
新增语义诊断不能追认旧门槛通过，也不能消除旧 scorer 的未决语义。

issue 的 100% 保留门槛针对可容纳的必需事实进入准入证据。后续联合合同还要求真实输出保留；
新协议原子性和 copy 路径属于额外明确冻结的验证条件。不能把离线输入覆盖当作真实输出成功，
也不能把新实验规则描述为 issue 原文已经指定的唯一实现方案。

两次真实请求使用量合计输入 6221、输出 2234 token，输出包含 reasoning。
按运行时冻结峰时全未命中费率计算的费用上界为 CNY 0.030314，不是账户账单金额。
响应模型名为 deepseek-flash；请求别名及相同 fingerprint 不能证明锁定历史物理模型。
本次 v9 仅返回 text 部分，未实际使用 copy；ASCII 样本也不构成线上 Unicode 保真证据。
语义审阅者为 assistant，非独立人工审阅，不能成为关键判定的唯一依据。
