- 完整投影、窗口缩减和片段选择使用同一组固定预算、指令与输入。窗口对照执行真实窗口触发器和缩减持久化。
- 36 个样例覆盖原始回归、两组固定压力变体、超大/混合 Source、位置事实、metadata 压力、精确字面量、UTF-8、失败和取消。
- v3 按结构分配轮转机会、延后完全重复副本，联合门槛同时验证三个数据集和两条基线；未选择的位置不获得代表片段的引用权限。
- 字节与字符偏移、内容和投影哈希、片段身份、遗漏及完整性状态进入逐样本结果。
- 决策验证全部实验组的生成覆盖；正常预算拒绝与运行失败分开。已准入的部分窗口仍需完成生成评分。
- 私有审计按返回调用持久化，保留中断前的输出及用量；未完成运行不能被当作完整聚合读取。
- 线上联合门槛和五组请求预算已实现；独立 smoke 不计入正式矩阵，三个数据集必须共同验证实际生成保留、审计和 usage。
- 实际生成为空或缺失必要事实时，即使输入保留完整也不能授权后续；人工审计不能改写原始执行、候选出处和用量。
- 生成事实、独立精确字面量、重复候选、支持和归因错误、请求与 token 用量分别汇总，未测指标保持 null。
- 本地受控输出贯通真实生成管线和 CLI 的运行、审计、报告重算；未访问线上 provider。
- 未修改生产 Source 投影、注册表、提取、reconciliation、检索、生命周期、公共 API 或生产游标。

## 结论的边界与不确定性

“必要事实可共同容纳”使用带有真实片段身份与偏移包装的参考输入判定，不是任意语义压缩策略的最优可行性证明。
选择策略不能访问标注；本评测不通过调整既有 v1 参数或读取答案来强行获得通过结果。
要改善候选，需另立策略版本、冻结配置并重新比较；失败的候选本身也是有效评测发现。

UTF-8 安全指不切断码点且保留 CRLF 配对，不保证每个片段都包含完整字素簇；连续片段拼接恢复原始字节。
片段引用属于评测契约，生产 SourceRef 尚不能据此宣称具备同等片段引用能力。提供支持范围也不证明模型实际使用了该范围。

真实执行边界是本地 SQLite、Source 与协程。未验证真实宿主 payload、OceanBase、跨进程工作器或远端 provider 取消。
私有 journal 验证进程内取消和额度耗尽时保留已返回响应，不保证断电恢复、自动续跑或远端停止计费。
生成用量只汇总已返回的已知 usage；失败请求用量可能不完整，不推算货币成本。

人工审计可以消除未决语义，但不能覆盖未准入支持、已知禁止事实或精确字面量错误。
尚无真实模型输出的人审样本，因此受控回放通过不能证明线上语义评分质量。
#2069 的宿主所有权与真实 payload 结论尚未接入；若未来需要生产设计，必须协调同一证据路径，避免重复清洗方案。

既有 LongMemEval lineage 验收测试因 #1975 的 `ScopedAtomicMemory.evidence` 能力缺口跳过，evaluation 全量类型检查也在该处报告一项错误。
新增评测模块和根工程类型检查通过。这个既有问题不构成对本 issue 增加生产 API 的理由。
