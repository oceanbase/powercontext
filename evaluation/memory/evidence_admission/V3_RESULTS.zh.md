# V3 离线比较结果

完成 36 个样例 × 5 个实验组 × 3 档预算 × 3 次重放，共 1620 个样本。联合输入准备门槛通过，
可共同容纳的必要事实保留为 495/495；真实 provider 请求为 0，最终生产决策仍为 `insufficient_evidence`。
这是冻结合成数据范围内的输入准备结果，不是线上提取质量、真实宿主覆盖或生产验收结论。

## 实现与冻结

- 新增 `bounded-fragments-v3`，默认实验仍为 v1；生产 `src/`、公共 API 和源投影没有修改。
- 按投影路径分成正文、用户 metadata、来源元数据，固定组间轮转机会为 2:1:1；组内字段再轮转。
  这不是字节占比保证或可信角色分层。正文首尾获得前两次机会，所有字段继续有资格竞争预算。
- 每个 Source/字段内优先选择完全不同值的代表片段，再安排重复副本；原始字节、类型、位置与身份保持。
  不进行语义筛选、近似去重或跨 Source 合并；代表片段不能为其他出现位置补造支持。
- 保留 512 字节分片、原始记录/UTF-8/CRLF 边界、单次预算、16 次调用和累计 8 倍预算上限，没有增加补扫页。
- 联合命令绑定三个必需数据集及运行/代码哈希，缺失数据、已知丢失、普通样例意外不可用或任一基线退化都会阻止离线通过。
- 策略、新增 fixture 与 catalog 在实现和运行前冻结；冻结文件校验无变化。
  [冻结记录](results/v3-freeze.json)和[算法契约](V3_PROTOCOL.md)保留相应身份与规则。

| 原有变体压力集 | 360 | 105/171 | 159/171 | 171/171 |

四个原有 v2 失败组合全部修复，12 个重复失败样本降为 0：
`validation-off-center-facts` 的 2K/4K/8K 均从 2/3 提升到 3/3，
`validation-metadata-pressure` 的 2K 从 1/2 提升到 2/2。原始集维持 216/216。

新增八个样例覆盖中部位置偏移、64 个 metadata 字段、字段重排、用户 metadata 事实、
只改变数字或否定词的近重复、Unicode/CRLF、跨片段边界事实。全部预算与重放保留 108/108。
这些样例由实现者在开发中编写并提前冻结，不是盲测或独立真实数据。

相对 v1 和 v2 分别有 324 对样本比较，均未观察到既有事实身份、字面量身份、完整证据状态、
失败/取消语义或发布行为退化。不可能完整的样例也参加集合包含比较，并继续保持 bounded。
原始集中所有样例的字面量计数为 v2 264/927、v3 270/927；该计数包含不可能完整样例，
不能误读成可共同容纳样例的字面量门槛失败，也不能把计数增加当作完整性证明。

1008 个历史 v1/v2 对照样本重新执行后，输入、支持、遗漏、窗口、状态和原有评分等价。
仅排除耗时字段，并通过当前模型补齐新增成本分解的空默认值。原有策略、清单、协议和历史结果字节未变。
核验见 [v3-baseline-replay.json](results/v3-baseline-replay.json)。

## 验证与剩余边界

- 111 项证据准入测试通过；与 LongMemEval 联合为 358 项通过、1 项既有能力缺口跳过。
- Ruff、格式、根工程及评测模块类型检查、两个锁文件检查通过；真实 wheel 在仓库外加载三个 v3 数据集通过。
- 全量 evaluation 类型检查仍有既有 `ScopedAtomicMemory.evidence` 缺失诊断；没有修改生产 API 掩盖该问题。
- 全部矩阵输入确定、无 Memory 写入、无生产游标推进、无预算越界，取消行为通过。
- 线上生成、真实归因、人工语义审计、真实 usage、真实宿主、OceanBase 与远端取消尚未验证。
- v3 单数据集报告始终不能单独授权生产后续；新增联合命令只验证离线准备，跨数据集线上审计门槛不在本轮实现范围。
- 任意固定预算子集仍可能遗漏任意文本中的事实。此次有限矩阵通过不构成普遍 100% 保留承诺。
- 工作区未提交，遵守本轮要求；issue 的已提交冻结及完整线上验收条件未满足。
