# Home page backdrop sources

Photographs behind the home page stages. The published crops live in `public/backdrops/` as WebP at 960, 1600 and 2400 pixels wide; `src/components/home/backdrop.tsx` serves them and renders the credit under each stage.

| File | Source | Use |
| --- | --- | --- |
| `iris-motion.jpg` | "Blue irises with motion blur" by Eugene Golovesov, [Unsplash](https://unsplash.com/photos/blue-irises-with-motion-blur-cJIUBpFEDBw), Unsplash License. 2400×1513. | Ground of the hero stage (`iris-motion-{960,1600,2400}.webp`) |
| `lupine-motion.jpg` | "Blurred blue and purple flowers with green foliage" by Eugene Golovesov, [Unsplash](https://unsplash.com/photos/blurred-blue-and-purple-flowers-with-green-foliage-PFDRQ6C8SV0), Unsplash License. 2400×1533. | Ground of the continuity stage, behind the Dashboard window (`lupine-motion-{960,1600,2400}.webp`) |

Both are free to use under the [Unsplash License](https://unsplash.com/license) and are credited on the home page.
