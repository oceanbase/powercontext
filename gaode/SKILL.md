# 周边地点推荐 Skill

## 工作流程

### 1. 需求解析
从用户输入中提取：地点类型（keywords）、时间上限、推荐数量（默认最多3个）、排序偏好（如“优先近的”）。

### 2. 坐标获取
如果用户提供的是地址而非经纬度，调用 `maps_geo` 工具将地址转换为经纬度坐标。

### 3. 周边搜索
调用 `maps_around_search` 工具，传入 `location` 和 `keywords` 进行搜索。

### 4. 路径规划与过滤
对于每个候选地点，调用 `maps_direction_walking` 工具，传入起点和终点经纬度，获取步行距离和时间。过滤掉步行时间超过用户设定上限的地点。

### 5. 排序与展示
将结果按步行距离由近到远排序，最多保留3个。以列表或表格形式呈现，每个地点需包含：
- 地点名称
- 地址
- 预计步行距离与时间
- 一句推荐理由

对于无法核实的信息（如是否安静、排队情况），必须标注“未核实”，不得编造。

## 异常处理
- 若未找到符合条件的3个地点，如实说明原因，并建议用户放宽条件。
- 若工具调用失败或返回异常，说明服务暂时不可用，不编造地点和路线。
