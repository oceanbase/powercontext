# Experience and Skill candidates

Use the available `generate_experience`, `propose_experience`, `generate_skill` or `propose_skill` operation only for the requested synthesis or correction. Supply exact returned evidence and current versions from this Scope. Generation creates a candidate, not approval or publication. Keep candidate decisions in the host's supported human/approval path. For managed-library search, external Skill registration and imports, read [Experience and Skills](experience-skills.md).
