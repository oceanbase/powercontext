# Codex Memory Source plugin

Import derived text under `.codex/memories` as immutable Source snapshots.

This directory is installed as `codex-memory-history` in a Source plugin directory. Set `CODEX_HOME` on the collection runner,
then create a `codex-memory-history` target through the Source target API. Use the local `preview` command before collecting.
See the [usage guide](../../../docs/en/docs/workflows/import-codex-memory.md) for the current workflow.
